## Q12 — Linux kernel privilege escalation (Dirty Cow / PwnKit)

**Question:** How are Linux kernel vulnerabilities like Dirty Cow (CVE-2016-5195) or PwnKit (CVE-2021-4034) exploited across HTB machines?

**Answer:**

## Recon

* **Identify Kernel and SUID Binaries:**
  * Check the running kernel version to identify known kernel vulnerabilities such as Dirty Cow:
    ```bash
    uname -a
    uname -r
    ```
    (seen on: Popcorn, Valentine, Altered)
  * Verify the presence of `pkexec` and inspect its permissions and timestamp:
    ```bash
    which pkexec
    ls -l /usr/bin/pkexec
    ```
    (seen on: Pressed, Paper, Routerspace)
  * **PwnKit Pre-check & Caveats:**
    * `pkexec` must have the SUID bit set (`-rwsr-xr-x`) to allow privilege escalation to root. If the SUID bit is missing (`-rwxr-xr-x`), the exploit will only run commands as the current user, failing escalation (seen on: Paper, Routerspace).
    * `pkexec` package version numbers were not bumped when patched; check the binary modification date (e.g., binaries unmodified since mid-2021 are likely vulnerable to CVE-2021-4034) (seen on: Pressed).

## Privilege Escalation

### Dirty Cow (Linux Kernel 2.6.22 < 3.9)
Dirty Cow exploits a race condition (via `/proc/self/mem` or `PTRACE_POKEDATA`) to write to read-only memory, often targeting `/etc/passwd` to add an arbitrary root user.

* **Exploit Search:**
  * Multiple variants are available in `searchsploit`:
    * `exploits/linux/local/40616.c` (SUID method)
    * `exploits/linux/local/40847.cpp` (/etc/passwd method)
    * `exploits/linux/local/40838.c` (PTRACE_POKEDATA write access)
    * `exploits/linux/local/40839.c` (PTRACE_POKEDATA /etc/passwd method)
    * `exploits/linux/local/40611.c` (/proc/self/mem write access)
    (seen on: Valentine)

* **Compiling and Running `dirty.c`:**
  1. Compile the exploit on the target:
     ```bash
     gcc -pthread dirty.c -o dirty -lcrypt
     chmod +x dirty
     ```
  2. Execute the compiled binary and provide a new password:
     ```bash
     ./dirty
     ```
     *(Note: The process may hang after backing up `/etc/passwd` and writing to `mmap`; kill it after waiting if needed)*
  3. Switch to the newly created root account:
     ```bash
     su - firefart
     ```
     (seen on: Popcorn)

### PwnKit (CVE-2021-4034)
PwnKit abuses an empty `argc` argument handling flaw in SUID-root `pkexec`.

* **Execution via Python PoC:**
  * Upload and run a Python implementation of the exploit (e.g., Joe Ammond's PoC) to trigger execution as root:
    ```bash
    python3 CVE-2021-4034.py
    ```
    (seen on: Antique)
