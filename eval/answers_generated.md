**Key take‑aways for HTB Windows boxes**

1. **Token‑impersonation tricks** (Lonely Potato, EfsPotato, GenericPotato, HWND broadcast) are repeatedly successful.  
2. **Service‑related misconfigurations** (insecure permissions, UsoSvc, NSClient++) provide a straightforward path to SYSTEM.  
3. **Writable temporary directories** (Checkmk, generic temp‑file abuse) allow planting of read‑only executables that run as SYSTEM.  
4. **Privilege‑escalation scanners** (Windows‑Exploit‑Suggester) are commonly used to pinpoint kernel or IE‑related exploits.  
5. **SQL Server impersonation** (`OPENROWSET BULK`) is another recurring vector.

## Q7 — MS17-010 EternalBlue exploitation

**Question:** What is MS17-010 (EternalBlue) and which HTB machines demonstrate its exploitation?

**Answer:**

**MS‑17‑010 (EternalBlue)**  
- An unauthenticated remote‑code‑execution vulnerability in the Windows SMB protocol.  
- Famously leaked by the Shadow Brokers and used to drive the WannaCry ransomware worm in 2017.  
- The Metasploit module for MS‑17‑010 is more stable than most Python‑based scripts, but both can be used for exploitation.

**HTB machines that demonstrate its exploitation**  
- **htb‑blue** – The “Shell as System > Background” and “Shell as System > Metasploit” paths show the use of the Metasploit MS‑17‑010 exploit to gain a system‑level shell. (seen on: htb‑blue)  
- **htb‑legacy** – The “System Shell > MS‑17‑010 > Locate Exploit” path illustrates using a Python script (from the helviojunior fork of worawit’s MS‑17‑010 repo) to upload and execute a payload via the vulnerability. (seen on: htb‑legacy)
